# EduMatrix M3 已知限制

## 阶段结论

M3-001~011 已获得契约、持久化、权限、前端和浏览器证据。M3-012 仍为 `PENDING`，阶段总状态保持 `IN_PROGRESS`，不能自动进入 M4。

## 真实模型闭环

- M3 资源生成和 Prover/Challenger/Judge 审核需要严格 JSON 输出。自动 API 测试使用结构化确定性替身，只证明 Schema、流程、权限和持久化。
- 本地浏览器使用当前 deterministic provider 时，诊断角色完成，但生成角色收到非 JSON 输出，界面如实显示 `M3 generator did not return raw JSON`。
- 尚未证明真实模型的事实准确率、幻觉率、教学质量、三画像内容质量或人工专家签字。

## FAISS 与媒体资源

- 当前交互工件明确运行在 `safe_deterministic_simulation`，不执行外部代码或网络，不冒充真实 FAISS 检索。
- `data/` 不在 Git 中。真实教材与索引必须依次运行：

  ```bash
  python scripts/collect_ml_multimodal_data.py --download
  python scripts/ingest_to_faiss.py
  ```

- 本轮已实际执行上述命令。GitHub 元数据查询可达，但仓库 pack/blob 传输连续失败或停滞；官方 codeload 探测可下载，但平均仅约 `26 KB/s`。因此尚未获得 13 个教材源，不能声明真实 FAISS 可用。
- ingestion 当前只扫描 `data/raw`，排除用户上传、已有索引、`.git` 和 `.partial`。本轮结果为 `0 files -> 0 chunks`，脚本以退出码 1 拒绝写入空索引，避免“打印成功但索引为空”的假阳性。

- 全量回归缺少 `data/animations` 和 7 个具备真实教材来源的 `data/patches` 图片，因此 7 项资源相关测试失败。
- Git 历史、`origin/main` 和仓库脚本均未提供这 7 张 patch 的权威源。VisRAG 已删除指向不存在文件的硬编码“教材切片”回退，只会注册 source 非空且本地文件真实存在的图像证据。
- 动画门禁要求至少 20 个知识点、60 个真实视频；现有下载脚本依赖外部平台、`yt-dlp`、下载体量和版权选择，不能用占位视频绕过。

## 数据库与账号

- `edumatrix.db` 是本地运行数据，不进入 Git。后端启动时自动初始化。
- 初始学生和教师账号依赖 `python scripts/seed_students.py`。本轮浏览器验收使用后端内置的 `demo-student` 演示账号，不代表生产账号体系验收。
