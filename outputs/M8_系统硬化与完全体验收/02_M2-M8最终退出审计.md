## 3. M8 安全与部署审计

### 3.1 身份与权限

- 运行授权矩阵覆盖 47 个认证、角色、owner、organization 和管理动作案例，结果 47/47。
- 默认源码模式不会创建公开已知的教师/管理员账号；只有显式 `EDUMATRIX_DEMO_MODE=1` 才启用评委演示账户。
- M7 集成管理仅管理员可用；跨组织事件入队返回 409，学习者访问返回 403。
- 401 与 403 都属于未认证/无授权场景的 fail-closed 行为，具体状态取决于请求是否已进入对象权限判断。

### 3.2 密钥、日志与隐私

- 模型 Key 只允许后端环境配置；前端不保存、不发送、不测试第三方 Key。
- 健康接口和部署预检只返回能力布尔值与非敏感模式，不含 Key、端点值或原始供应商异常。
- 后端启动日志只记录 `endpoint_configured=True/False`，不打印实际端点。
- 已移除未跟踪的硬编码令牌代理脚本和含令牌形态值的代理日志；复扫 `app`、`frontend/src`、`scripts`、`packaging` 为 `suspicious_files=0`。

### 3.3 部署真实性

- 当前确定性演示预检为 `ready`：数据库可用、迁移为 `20260802_013`、2 门已发布课程、21 份文档、21 条来源引用、前端构建存在、canonical hash 检索可用、无 blocker。
- `text_model.available=false` 和 `vision_model.available=false` 不阻断确定性演示；只说明当前没有配置真实模型。
- `retrieval_backend=canonical_hash` 是可验证的本地检索路径；`faiss_available=false` 不应被误报为整个系统不可运行。
- Windows 一键运行是评委默认路线，Docker 只是可选部署方式。

### 3.4 代码执行边界

- trusted-local 模式已验证普通代码可运行，并阻断 `os` 导入。
- 该模式面向本地学术演示，不等同生产级、强隔离、多租户不可信代码执行环境。
- 生产化需要独立容器/虚拟化、资源配额、系统调用限制、网络隔离和宿主机安全审计，当前不作已完成声明。
